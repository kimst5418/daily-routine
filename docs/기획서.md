# 루틴 체크 앱 기획서 (v1)

## 1. 서비스 개요
- 서비스명(가칭): 루틴 체크
- 한 줄 정의: 반복적으로 수행하는 개인 테스크를 관리하고, 일별 체크 및 달력 확인, 지연 알림까지 제공하는 개인용 앱
- 목적
  - 운동/공부/생활 습관 기록의 지속성 강화
  - "누락하기 쉬운 행동"을 지연 알림으로 보완

## 2. 문제 정의
- 반복 활동은 계획은 쉬우나 기록이 자주 누락된다.
- 출근/퇴근처럼 짝으로 관리해야 하는 행동은 두 번째 행동을 놓치기 쉽다.
- 기존 메모/캘린더만으로는 완료 여부 추적과 습관화가 어렵다.

## 3. 목표
- 반복 테스크의 등록과 수행 체크를 10초 내 처리할 수 있게 한다.
- 달력 기반으로 과거 수행 기록을 빠르게 확인한다.
- 특정 행동 이후 N시간/N분 후 리마인드 알림으로 누락을 줄인다.

## 4. 핵심 사용자
- 본인 1인 사용자(개인 생산성 관리 목적)
- 대표 시나리오
  - 운동 루틴 체크
  - 공부 루틴 체크
  - 출근 체크 후 퇴근 체크 알림

## 5. 핵심 가치 제안
- 반복 일정 + 수행기록 + 지연알림을 하나의 흐름으로 통합
- 빠른 입력(체크 중심 UI)으로 지속 사용성 강화
- 날짜 단위 회고가 쉬운 달력 UI 제공

## 6. 기능 범위

## 6.1 요구사항 1: 반복 테스크 + 체크 + 달력
- 반복 테스크 생성/수정/삭제
- 반복 규칙
  - 매일
  - 특정 요일(예: 월/수/금)
  - 향후 확장: 주기 간격(예: 2일마다)
- 오늘의 테스크 목록 제공
- 테스크 수행 체크
- 달력에서 일별 기록 확인

## 6.2 요구사항 2: 지연 알림
- 특정 테스크 수행 시점 기준 N시간/N분 후 알림 생성
- 사용 예
  - 출근 체크 완료 -> 9시간 후 퇴근 체크 알림
- 루틴 기능과 별개 도메인으로도 확장 가능한 구조

## 7. MVP 정의
- 포함
  - 테스크 CRUD
  - 반복 규칙(매일/요일 지정)
  - 오늘 체크
  - 달력 조회
  - 지연 알림 1개 이상 설정
- 제외
  - 멀티 계정
  - 복잡한 통계/리포트
  - 외부 연동(캘린더/메신저)

## 8. 화면 구성(초안)
- 홈(오늘)
  - 오늘 대상 테스크 목록
  - 빠른 완료 체크
- 달력
  - 월간 뷰
  - 날짜 선택 시 수행 내역
- 테스크 관리
  - 반복 규칙/카테고리/활성화 설정
- 알림 설정
  - 기준 테스크, 지연 시간(시간/분), 메시지 설정

## 9. 성공 지표(초기)
- 주간 체크 수행률
- 지연 알림 이후 수행 전환률
- 7일 연속 사용 일수

## 10. 제약 및 가정
- 개인 단독 사용 기준
- 초기 버전은 로컬 저장소 중심 운영
- 알림 신뢰성이 핵심 품질 항목

## 11. 향후 확장
- 통계 대시보드(주간/월간)
- 위젯/단축 액션
- 백업/복구 및 동기화
