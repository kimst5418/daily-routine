# 현재 진행 상황

## 1. 프로젝트 방향
- 앱 이름: `루틴 한칸`
- 앱 형태: Android 앱 우선
- 프레임워크: Expo + React Native + TypeScript
- 백엔드: 없음
- 저장 방식: 로컬 저장만 사용
- 데이터 이동: 추후 import/export 지원 예정
- 웹/Electron: 현재 범위에서 제외

## 2. 핵심 정책 요약
- 반복 테스크를 생성하고 날짜별로 수행 여부를 기록한다.
- 1회성 테스크는 현재 범위에서 제외하고 루틴 전용으로 운영한다.
- 달력에서 날짜별 완료 현황을 확인한다.
- 알림 연동 테스크는 시작 시 `IN_PROGRESS`가 되고, 지연 시간 기준 예정 시각에 알림을 시작할 수 있다.
- 알림은 반복 간격(분) 기준으로 필요한 확인을 리마인드하는 구조다.
- 알림은 시작 시 최대 횟수만큼 한 번에 예약하고, 완료/삭제/비활성화 시 예약 전체를 취소한다.

## 3. 현재 구현 완료 범위

### 3-1. 앱/환경
- Expo 프로젝트 생성 완료
- Android 에뮬레이터 실행 확인 완료
- Node 버전 `20.20.1`로 정리 완료
- Expo Go에서 `expo-notifications` 충돌 회피 처리 완료
- development build 준비 설정 추가
  - `expo-dev-client`
  - `expo-notifications` plugin
  - Android 기본 알림 채널
  - `eas.json` development profile

### 3-2. 데이터 계층
- SQLite 초기화 구현 완료
- 아래 구조로 전환 완료
  - `task_templates`
  - `recurrence_rules`
  - `task_tickets`
  - `reminder_rules`
  - `reminder_events`
- `task_tickets`에 생성 시점 기준 `reminder_rule_id` 스냅샷 저장
- 테스크 조회 row를 화면용 모델(`TodayTaskItem`)로 묶는 매핑 정리 완료
- `reminder_events`를 상태 이력이 아닌 활성 예약 묶음 저장 구조로 단순화

### 3-3. 테스크 기능
- 샘플 테스크 시드 생성
- 새 테스크 생성 가능
- 활성 테스크 수정 가능
- 활성 테스크 비활성화(삭제) 가능
- 루틴 생성 시 기본 카테고리는 `기타`
- 반복 방식 지원
  - 매일
  - 특정 요일 반복
- 오늘 화면에서 완료 체크 가능
- 선택 날짜에서도 완료 체크 가능
- 알림 연동 테스크는 `PENDING -> IN_PROGRESS -> DONE` 흐름 사용

### 3-4. 달력 기능
- 월간 달력 표시
- 이전/다음 월 이동 지원
- 좌우 스와이프로 이전/다음 월 이동
- 연도 이동 + 월 선택 분리형 모달
- 날짜 셀에 달성률 단계형 색상 표시
- 상태/카테고리 필터가 달력 전체에 적용
- 날짜 선택 시 상세 목록 표시
- 기본 선택 날짜는 오늘
- 오늘 날짜/선택 날짜를 서로 다른 테두리 강조로 표시
- 과거 날짜 체크 수정 가능
- 기록 탭은 헤더 없이 달력 중심 레이아웃으로 정리
- `오늘` 이동 버튼을 달력 내비게이션에 통합

### 3-5. 알림 규칙 기능
- 루틴 폼 안에서 접히는 상세 설정으로 알림 규칙 생성/수정 가능
  - 지연 시간(분, 최소 1분)
  - 반복 간격(분)
  - 최대 알림 횟수
  - 메시지
- 루틴당 활성 알림 규칙 1개만 허용
- 알림 규칙 비활성화 가능
- 연결된 루틴이 비활성화되면 관련 알림 규칙도 함께 비활성화

### 3-6. 알림 이벤트 기능
- 알림 연동 테스크를 시작해 `IN_PROGRESS`로 바꾸면 예정 시각 기준으로 알림 예약 묶음 생성
- Expo Go에서는 실제 OS 알림 대신 내부 예약 이벤트 기록
- `IN_PROGRESS` 진입 시 최대 알림 횟수만큼 OS 알림을 한 번에 예약
- `IN_PROGRESS -> DONE`, 상태 롤백, 오늘 티켓 삭제, 템플릿/규칙 비활성화 시 관련 예약 알림 전체 취소
- `reminder_events`는 현재 살아 있는 예약 묶음만 저장
- 반복 재스케줄 엔진 제거

### 3-7. UX/UI 정리
- 오늘 탭 상단을 요약 중심으로 정리
- 오늘/달력 상세 카드에서 상태 배지와 행동 중심 버튼 문구 적용
- 기록 탭 필터 영역을 압축해 달력이 더 먼저 보이도록 정리

- 오늘 탭/달력 상세의 테스크 카드 UI 공통 컴포넌트화 완료
- 상단 탭 헤더를 작은 아이콘 + 라벨 바 구조로 정리

## 6. 현재 확인된 제약
- Expo Go에서는 `expo-notifications` 실제 예약/푸시 기능을 완전하게 검증할 수 없다.
- development build 준비는 되었지만, 백그라운드/앱 종료 상태에서의 실제 반복 알림 보장은 아직 검증 전이다.
- 반복 알림은 현재 OS 예약을 한 번에 여러 개 생성하는 방식으로 전환 중이며, development build에서 실제 기기 검증이 필요하다.
- import/export는 아직 구현 전이다.
- 설정 탭의 알림 설정은 아직 껍데기만 있고 실제 전역 설정 저장/연동은 미구현이다.
- 카테고리 추가/제거는 현재 앱 메모리 상태 기준이며, 별도 저장/마이그레이션은 아직 미구현이다.
- 라이트/네이비 테마는 시스템 전환까지 연결되었지만, 실제 기기 기준 대비/가독성 점검은 추가 검증이 필요하다.
