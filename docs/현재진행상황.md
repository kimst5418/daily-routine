# 현재 진행 상황

## 1. 현재 기준
- 현재 제품의 실제 동작 기준 문서는 [제품명세서](/Users/kim/projects/llm/secretary/docs/제품명세서.md) 이다.
- 이 문서는 상세 기능 설명보다 `현재 상태 요약`, `남은 이슈`, `다음 우선순위`만 관리한다.

## 2. 현재 상태 요약
- 앱 이름: `루틴 한칸`
- 플랫폼: Android 우선
- 프레임워크: Expo + React Native + TypeScript
- 저장 방식: SQLite 로컬 저장
- 탭 구성
  - `오늘`
  - `기록`
  - `루틴`
  - `설정`
- 데이터 구조
  - `task_templates`
  - `recurrence_rules`
  - `task_tickets`
  - `reminder_rules`
  - `reminder_events`

## 3. 최근 반영 완료
- 오늘/기록 탭 시간 표시 규칙 공통화
- 기록 탭 달력 높이 압축
  - 최소 5주, 필요 시 6주
- 탭 전환 시 스크롤 상단 이동
- 테마 선택 영속화
- 루틴 수정 시 상단 폼으로 이동하는 UX 보강
- 지연시간 입력 UI를 `시간:분` 형식으로 조정
- 입력 최대값 초과 시 자동 보정 + 흔들림 피드백 추가
- 로컬 APK 빌드 기준 README 정리

## 4. 현재 남은 주요 이슈
- development build/실기기 기준 실제 알림 검증이 더 필요하다.
- 설정 탭의 카테고리 추가/제거는 아직 영속화되지 않았다.
- 설정 탭의 전역 알림 설정은 아직 껍데기 상태다.
- import/export는 아직 구현 전이다.
- 실제 출시용 서명/배포 체계는 별도 정리가 필요하다.
