# 현재 진행 상황

## 1. 프로젝트 방향
- 앱 형태: Android 앱 우선
- 프레임워크: Expo + React Native + TypeScript
- 백엔드: 없음
- 저장 방식: 로컬 저장만 사용
- 데이터 이동: 추후 import/export 지원 예정
- 웹/Electron: 현재 범위에서 제외

## 2. 핵심 정책 요약
- 반복 테스크를 생성하고 날짜별로 수행 여부를 기록한다.
- 1회성 테스크는 현재 범위에서 제외하고 루틴 전용으로 운영한다.
- 달력에서 날짜별 완료 현황을 확인한다.
- 특정 테스크 종료 시각 기준으로 N시간/N분 뒤 알림을 시작할 수 있다.
- 알림은 반복 간격(분) 기준으로 필요한 확인을 리마인드하는 구조다.
- 알림 종료 조건은 현재 `수동 해제`만 지원한다.

## 3. 현재 구현 완료 범위

### 3-1. 앱/환경
- Expo 프로젝트 생성 완료
- Android 에뮬레이터 실행 확인 완료
- Node 버전 `20.20.1`로 정리 완료
- Expo Go에서 `expo-notifications` 충돌 회피 처리 완료
- development build 준비 설정 추가
  - `expo-dev-client`
  - `expo-notifications` plugin
  - Android 기본 알림 채널
  - `eas.json` development profile

### 3-2. 데이터 계층
- SQLite 초기화 구현 완료
- 아래 구조로 전환 진행 중
  - `task_templates`
  - `recurrence_rules`
  - `task_tickets`
  - `reminder_rules`
  - `reminder_events`

### 3-3. 테스크 기능
- 샘플 테스크 시드 생성
- 새 테스크 생성 가능
- 활성 테스크 수정 가능
- 활성 테스크 비활성화(삭제) 가능
- 반복 방식 지원
  - 매일
  - 특정 요일 반복
- 오늘 화면에서 완료 체크 가능
- 선택 날짜에서도 완료 체크 가능
- 알림 연동 테스크는 `PENDING -> IN_PROGRESS -> DONE` 흐름 사용

### 3-4. 달력 기능
- 월간 달력 표시
- 주간 달력 표시
- 이전/다음 이동 버튼 동작
- 좌우 스와이프로 이전/다음 월/주 이동
- 연/월 직접 선택 모달
- 날짜별 완료 수 / 전체 수 표시
- 날짜 셀에 `완료/전체` 비율 및 진행 바 표시
- 상태/카테고리 필터가 달력 전체에 적용
- 날짜 선택 시 상세 목록 표시
- 주 보기에서 1주 1행 고정 및 더 많은 테스크 미리보기
- 기본 선택 날짜는 오늘
- 오늘 날짜 강조 표시
- 과거 날짜 체크 수정 가능

### 3-5. 알림 규칙 기능
- 알림 규칙 생성 가능
  - 기준 테스크(종료 시각 기준)
  - 지연 시간(시간/분, 최소 1분)
  - 반복 간격(분)
  - 메시지
- 테스크당 활성 알림 규칙 1개만 허용
- 알림 규칙 비활성화 가능
- 연결된 테스크가 비활성화되면 관련 알림 규칙도 함께 비활성화

### 3-6. 알림 이벤트 기능
- 알림 연동 테스크를 시작해 `IN_PROGRESS`로 바꾸면 예정 시각 기준으로 알림 이벤트 생성
- Expo Go에서는 실제 OS 알림 대신 내부 예약 이벤트 기록
- 수동 해제 가능
- 기한이 지난 pending 알림 이벤트를 반복 간격 기준으로 다음 시각에 재스케줄
- 반복 종료 시점(`repeat_until`)을 넘기면 이벤트를 `EXPIRED`로 종료
- 연결된 테스크가 비활성화되면 관련 pending 알림 이벤트 자동 취소
- 오늘 탭에서는 살아 있는 pending 알림 기준으로만 종료시간 표시
