# 루틴 한칸 제품명세서

## 1. 문서 목적
- 현재 앱의 실제 동작 기준을 한 곳에 정리한다.
- 상위 기획서보다 더 구체적으로, 화면/상태/저장 규칙을 명시한다.
- 이후 수정 작업은 이 문서를 기준으로 판단한다.

## 2. 제품 개요
- 앱 이름: `루틴 한칸`
- 플랫폼: Android 우선
- 프레임워크: Expo + React Native + TypeScript
- 저장소: SQLite 로컬 저장
- 사용자 범위: 개인 1인 사용
- 핵심 목적:
  - 반복 루틴을 빠르게 기록한다.
  - 날짜별 완료 현황을 달력에서 확인한다.
  - 시작 이후 지연 알림으로 누락을 줄인다.

## 3. 정보 구조
- 탭 구성
  - `오늘`
  - `기록`
  - `루틴`
  - `설정`
- 주요 데이터 구조
  - `task_templates`: 루틴 원본 정의
  - `recurrence_rules`: 반복 규칙
  - `task_tickets`: 날짜별 실제 수행 건
  - `reminder_rules`: 루틴별 알림 규칙
  - `reminder_events`: 현재 살아 있는 예약 알림 묶음

## 4. 상태 규칙
- 티켓 상태
  - `PENDING`: 시작 전
  - `IN_PROGRESS`: 시작 후, 완료 전
  - `DONE`: 완료
- 알림 규칙이 있는 티켓
  - `PENDING -> IN_PROGRESS -> DONE`
- 알림 규칙이 없는 티켓
  - `PENDING -> DONE`
- `PENDING`으로 되돌리면 `opened_at`, `completed_at`은 초기화된다.
- `opened_at`은 `PENDING -> IN_PROGRESS`일 때만 기록된다.
- `PENDING -> DONE` 직행 완료 시 `opened_at`은 기록하지 않는다.

## 5. 시간 표시 규칙
- 오늘 탭과 기록 탭은 동일한 표시 규칙을 사용한다.
- `IN_PROGRESS`
  - `시작시간: HH:MM`
- `DONE`
  - 시작/완료 시간이 둘 다 있으면 `HH:MM ~ HH:MM`
  - 시작시간이 없고 완료시간만 있으면 `완료시간: HH:MM`

## 6. 오늘 탭 명세
- 상단 헤더 제목은 `매일 한칸`
- 오늘 날짜와 요일을 표시한다.
- 상단 요약 카드에 `예정 / 진행중 / 완료` 개수를 표시한다.
- 오늘 날짜의 `task_tickets`만 표시한다.
- 카드 공통 요소
  - 상태 배지
  - 카테고리
  - 상태별 시간 표시
  - 액션 버튼
- 상태별 액션
  - `PENDING`
    - 알림 규칙 있음: `시작`
    - 알림 규칙 없음: `완료`
  - `IN_PROGRESS`
    - `예정`
    - `완료`
  - `DONE`
    - `예정`
- 카드의 `X` 버튼은 오늘 티켓만 삭제한다.
- 탭 전환으로 오늘 탭에 진입하면 스크롤은 상단에서 시작한다.

## 7. 기록 탭 명세
- 월간 달력 중심 레이아웃을 사용한다.
- 달력은 `최소 5주`, 필요한 달만 `6주`를 표시한다.
- 날짜 셀은 완료율 단계형 색상만 표시한다.
- 필터
  - 상태
  - 카테고리
  - 필터 초기화
- 날짜를 선택하면 하단에 해당 날짜의 티켓 상세 목록을 표시한다.
- 상세 목록 카드는 오늘 탭과 동일한 시간 표시 규칙을 사용한다.
- 탭 전환으로 기록 탭에 진입하면 스크롤은 상단에서 시작한다.

## 8. 루틴 탭 명세
- 상단 폼에서 루틴 생성/수정을 수행한다.
- 폼 구성
  - 제목
  - 카테고리
  - 반복 방식
  - 반복 요일
  - `종료 알림 설정`
  - 알림 메시지
- 알림 설정은 접히는 섹션으로 제공한다.
- 지연시간 입력
  - 입력 형식: `지연시간(시간:분)`
  - UI 형태: `숫자칸 : 숫자칸`
  - 저장 형식: 총 분(`delay_minutes`)
  - 시간 최대값: `23`
  - 분 최대값: `59`
  - 초과 입력 시 최대값으로 보정하고 입력칸을 흔들어 피드백을 준다.
- 반복(분)
  - 최대 `10`
  - 초과 입력 시 `10`으로 보정하고 입력칸을 흔든다.
- 최대 횟수
  - 최대 `10`
  - 초과 입력 시 `10`으로 보정하고 입력칸을 흔든다.
- 활성 루틴 목록
  - 제목
  - 카테고리
  - 반복 규칙 요약
  - 알림 규칙 요약
    - `알림: 1시간 30분 후 / 3분 간격 / 최대 5회` 형식
  - `수정`
  - `삭제`
- 활성 루틴에서 `수정`을 누르면
  - 폼 값이 주입되고
  - 루틴 탭 상단 폼으로 스크롤 이동하며
  - `수정 중` 상태를 표시한다.
- 탭 전환으로 루틴 탭에 진입하면 스크롤은 상단에서 시작한다.

## 9. 설정 탭 명세
- 테마 선택
  - `시스템`
  - `라이트`
  - `네이비`
- 테마 설정은 SQLite에 저장되며 앱 재실행 후 복원된다.
- 카테고리 추가/제거 UI를 제공한다.
- 알림 설정 전역 섹션은 아직 껍데기 상태다.
- 탭 전환으로 설정 탭에 진입하면 스크롤은 상단에서 시작한다.

## 10. 알림 동작 명세
- 루틴당 활성 알림 규칙은 1개만 허용한다.
- 알림 규칙은 루틴 시작 후에만 동작한다.
- `IN_PROGRESS` 진입 시
  - 지연 시간 기준 예정 시각을 계산한다.
  - 반복 간격과 최대 횟수 기준으로 OS 예약 알림을 한 번에 생성한다.
  - `reminder_events`에 현재 예약 묶음을 저장한다.
- 아래 경우에는 관련 예약 알림을 모두 취소한다.
  - `IN_PROGRESS -> DONE`
  - `IN_PROGRESS -> PENDING`
  - 오늘 티켓 삭제
  - 루틴 비활성화
  - 알림 규칙 비활성화

## 11. 저장/영속화 정책
- 저장됨
  - 루틴/반복 규칙
  - 날짜별 티켓 상태
  - 알림 규칙
  - 알림 이벤트
  - 테마 선택
- 아직 저장 안 됨
  - 설정 탭에서 추가/제거한 카테고리
  - 전역 알림 설정 껍데기

## 12. 현재 제약
- Expo Go에서는 실제 로컬 알림 검증이 제한적이다.
- development build/실기기 기준 실제 반복 알림 검증이 더 필요하다.
- 카테고리 설정은 앱 메모리 상태 기준이다.
- import/export는 아직 없다.
- 전역 알림 설정은 아직 구현 전이다.
